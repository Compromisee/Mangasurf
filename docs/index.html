Why it exists

Built around the awkward parts

Downloading images is the easy bit. Nearly all of the work is in what the sites do to stop you — and in not losing an hour of progress when one of them misbehaves.

link

Paste any link

The source is detected from the URL, including sites with tracking parameters — which used to silently return zero chapters. Aggregate installs resolve too, so madara.toonily is just Toonily.

extension

Hostile page layouts

Base64 payloads, decoy search endpoints, obfuscated readers and randomly named JS variables — each handled per source, each verified against the live site rather than guessed at.

image

Hotlink-protected art

Covers that 403 without the right referrer are fetched server-side and inlined, so they show up instead of a blank tile.

bolt

Several at once

Queue multiple series and download them in parallel. Every progress event is tagged with its job, so two books never mix their chapters.

restart_alt

Survives interruption

Chapter-level checkpoints, atomic writes and a per-job journal. A crash costs you the current chapter, not the run.

tune

Filters that work

Type, status, genre and chapter-count filters — with unknown values kept rather than silently erasing whole sources from the results.

Command line

Syntax

Enough flags to script with, short enough to remember.

BASICS# every chapter into one CBZ $ readerm https://mangadex.org/title/<uuid> # chapters 1-50 as a PDF, and an EPUB alongside it $ readerm --url <url> -c 1-50 -f pdf --also epub # one file per 10 chapters, with a custom name $ readerm --url <url> --per 10 --name-range "{title} Vol {start}-{end}" # pick up where an interrupted run stopped $ readerm resume SELECTIONS-c all  ·  5  ·  1-20  ·  1,5,10-20  ·  50-  ·  latest  ·  first
FINDING THINGS# every enabled source at once $ readerm search "chainsaw man" # one source, filtered by genre and length $ readerm search "cultivation" --source mangadex --genre Action --min-chapters 100 # open result 3, or download it directly $ readerm search "berserk" --open 3 $ readerm search "berserk" --download 3 FOR SCRIPTS$ readerm search "one piece" --urls # one URL per line $ readerm search "one piece" --json # machine readable
INTERACTIVE# numbered menu, no extra dependencies $ readerm menu # full-screen terminal UI (needs the tui extra) $ readerm-tui # the desktop app $ readerm-gui IN THE MENU number choose an item b back a level q quit
WHAT YOU HAVE$ readerm library # everything downloaded $ readerm library --check # find files that moved or vanished COVERS# rebuild covers for every CBZ in a folder, recursively $ readerm covers ~/Manga # preview without writing, or split a flat folder into series $ readerm covers ~/Manga --dry-run $ readerm covers ~/Manga --sort-only UPDATES$ readerm updates # new chapters for watched series
SETTINGS$ readerm config --list $ readerm config --set output_dir="D:\Manga" $ readerm config --set chapter_workers=5 SOURCES$ readerm sources # list them with their ranks $ readerm sources --disable nhentai $ readerm sources --rank mangadex=1 WHERE THINGS LIVE ~/.readerm/config.json settings and per-source config ~/.readerm/library.json what you have downloaded ~/.readerm/jobs/ crash-resume journals

Install

Two lines

Python 3.9 or newer. That is the whole prerequisite.

1

Clone it

Or download the ZIP from the releases page.

git clone https://github.com/Compromisee/ReaderM.git
2

Install it

[all] adds the desktop app and the TUI.

cd ReaderM && pip install -e ".[all]"
3

Run it

Start anywhere; they share one config.

readerm-gui
info

The base install covers the CLI and the menu. Optional extras: [gui] for the desktop app, [tui] for the full-screen terminal UI, [tray] for background downloading from the system tray.
