Getting started

Easy to start.
Delightful to master.

1

Install the engine

One command pulls the curl_cffi core, scrapers, TUI and servers — batteries included.

pip install "mangasurf[all]"
2

Search everything

Hit the omnibar once — 38 sources answer in a third of a second, interleaved and ranked.

mangasurf search "solo leveling"
3

Read anywhere

Grab CBZ / PDF / EPUB, or stream to your phone and e-reader over LAN + OPDS.

mangasurf server --port 8577
